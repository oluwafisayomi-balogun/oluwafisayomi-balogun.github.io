Baseline In progress

A personal finance tool for smarter investing in the Nigerian stock market: a price-trend scanner and a private portfolio tracker.

Open Baseline Try the demo
Role
Solo project
Stack
Python, JavaScript, Supabase (Postgres, Auth, row-level security), GitHub Actions, Vercel

Problem

My investing in the Nigerian stock market ran on a spreadsheet and manual price checks, and applying my own investing rules to each holding by hand was slow.

Solution

Data
Daily closing prices for 147 NGX-listed stocks and ETFs
Pipeline
A Python job on GitHub Actions each day works out daily moves, streaks and 5-day moving-average signals
Storage
History files committed to the repo, and Supabase Postgres for the tracker
Site
A static site on Vercel showing the scanner
Tracker
A private, multi-user portfolio tracker with magic-link sign-in
Rules
Investing rules applied to the latest closing prices, flagging what needs attention. You can personalize your own rules

Result

Live and still in progress: 147 instruments scanned every weekday, plus a private tracker with a demo mode that needs no account.
