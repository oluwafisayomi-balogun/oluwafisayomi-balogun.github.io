bc.fun Sports Bet Automation

A Python script that places single and combo bets on bc.fun through the site's own web API instead of its interface.

View on GitHub
Role
Solo project
Status
Finished in September 2025
Stack
Python, REST APIs, Chrome DevTools

Problem

Placing a bet means clicking through the website. This project shows the same thing done with a single function call.

Limits

  • It does not log in. The token is pasted in by hand.
  • The bet details are entered by hand, so it automates placing a bet, not choosing one.
  • It has no automated tests.
