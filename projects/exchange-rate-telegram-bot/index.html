Exchange Rate Telegram Bot

A Telegram bot that gives current exchange rates, Nigerian naira included, and sends a daily rate message to subscribers.

Open the bot View on GitHub
Role
Solo project
Stack
Python, aiogram, asyncpg, PostgreSQL (Neon), APScheduler, Docker, Fly.io

Problem

Checking a naira rate means leaving the app you are in for a website, and the ECB rates, a common free source, have no naira at all.

Solution

Interface
A Telegram bot built with aiogram: /start, /rates and inline buttons for 17 base currencies
Rates
open.er-api, which includes NGN
Storage
PostgreSQL on Neon in production and a JSON file in development, behind one interface
Scheduler
APScheduler sends a daily rate message to subscribers
Hosting
A Docker image on a single Fly.io machine

Result

Live on Fly.io, with rates for 17 base currencies and a daily broadcast to subscribers.
