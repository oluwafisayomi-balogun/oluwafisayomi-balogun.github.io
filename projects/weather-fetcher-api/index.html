Weather Fetcher API

A Flask app that turns a city name into current weather.

Try it live View on GitHub
Role
Solo project
Stack
Python, Flask, REST APIs, Render

Solution

Interface
A Flask web form where you type a city name
Lookup
A first call to OpenWeather finds the city's coordinates
Weather
A second call to OpenWeather fetches the weather for those coordinates
Hosting
Render. The live demo might take a while to load, because of Render itself

Result

Live on Render.
