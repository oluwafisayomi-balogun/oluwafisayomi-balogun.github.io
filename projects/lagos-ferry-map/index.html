Lagos Ferry Map

Public data on Lagos's ferry network, built so commuters and map apps can use it.

View the map Download the GTFS feed Map code on GitHub
Role
Data engineer and associate on a team project
Period
February 2025 to present
Stack
Node.js, Express, TypeScript, Drizzle ORM, PostgreSQL, Python, Jython, GTFS, OpenStreetMap, JOSM, Railway

Problem

Lagos has ferry routes but no public documentation of them, so commuters learn about them by word of mouth. The goal is to make the network easy to find, so more trips move from the roads to the water. I helped turn scattered sources into one dataset, published as a GTFS feed that Google Maps and other apps read, and refreshed every quarter.

Data

Jetties, routes and schedules from the LASWA list, Google Maps and OpenStreetMap, field contractors, operator interviews and GPS logs. Commuters and map apps use it to plan ferry trips.

How it works

Public sources and field surveys → forms app with a review queue → PostgreSQL → Python toolchain → GTFS feed → Google Maps, OpenStreetMap and the Mobility Database

  • A submission that changes a critical field is held for review instead of being applied. Critical means facility type, schedule flags, hyacinth season, or a fare rise of 50% or more.
  • The toolchain fingerprints the feed so its version only changes when the data does.

Result

Published as a public GTFS feed, and live on Google Maps, OpenStreetMap and the Mobility Database.
